# Quotes a fixed-rate loan for an applicant.

Computes the monthly payment for a fixed-rate loan from the requested amount, term and annual rate, and decides whether the applicant's credit score qualifies.

This project was generated by Notebook2API from a validated API documentation draft (see `prereqai-project.json` for the generator, contract version and draft it came from, and `prereqai-manifest.json` for the full file inventory).

## Endpoint

`POST /loan-quote` — Quotes a fixed-rate loan for an applicant.

Parameters:

| name | type | required |
|---|---|---|
| amount | float | yes |
| term_months | int | no |
| annual_rate | float | no |
| applicant | dict | yes |
| tags | list | no |

Response fields:

| name | type |
|---|---|
| monthly_payment | float |
| approved | bool |
| applicant_name | str |

## Run locally

```
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

The entrypoint is `app.main:app` (the `app` object in `app/main.py`). Interactive API docs are served by FastAPI at `/docs`, and the OpenAPI document is in `openapi.json`.

## Run with Docker

```
docker build -t generated-api .
docker run -p 8000:8000 generated-api
```

The image is based on `python:3.11-slim`. The listen address comes from the `HOST` and `PORT` environment variables (defaults `0.0.0.0` and `8000`).

## Behaviour

The generated handler does not run any notebook code. For a request whose input exactly matches one of the documented examples it returns that example's output (with an `X-Execution: documented-example` header); for any other valid request it answers `501 Not Implemented`.
